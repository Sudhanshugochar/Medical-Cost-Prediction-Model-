# 🏥 Medical Cost Prediction using Machine Learning

A supervised Machine Learning project that predicts **medical insurance costs** based on personal and lifestyle factors such as age, BMI, smoking habits, and region.  
This project focuses on understanding **regression logic, feature impact, and model evaluation** in a real-world healthcare scenario.

---

## 📌 Project Overview

Healthcare costs depend on multiple factors and vary significantly across individuals.  
This project aims to build a **regression-based ML model** to predict medical insurance charges and analyze which factors influence costs the most.

This project strengthened my understanding of:
- Supervised Learning (Regression)
- Data preprocessing & EDA
- Model evaluation metrics
- End-to-end ML workflow

---

## 🎯 Problem Statement

Given a dataset containing the following features:
- Age  
- Sex  
- BMI  
- Number of children  
- Smoking status  
- Region  

👉 Predict the **medical insurance cost (charges)** for an individual.

---

## 🧠 Machine Learning Approach

- **Learning Type**: Supervised Learning  
- **Task**: Regression  
- **Target Variable**: `charges`  
- **Input Features**: age, sex, bmi, children, smoker, region  

---

## 📂 Dataset

- **Dataset Name**: Medical Insurance Cost Dataset  
- **Source**: Public dataset (used widely for regression practice)  
- Contains both **numerical and categorical features**

## 📊 Model Evaluation Metrics

The model was evaluated using:
- **R² Score**
- **Mean Absolute Error (MAE)**
- **Mean Squared Error (MSE)**

These metrics help measure:
- Variance explained by the model  
- Average prediction error  
- Overall model performance  

---

## 📈 Key Insights

- Smoking status has a **major impact** on medical insurance costs  
- BMI and age significantly influence charges  
- Tree-based models handle non-linear relationships better  
- Feature importance helps explain model predictions clearly  

---

## 🚀 Results

- Achieved a reasonable **R² score**
- Predictions align well with actual medical costs
